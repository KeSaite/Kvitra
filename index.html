Built for my own servers

I started building Meows to check my own servers from my phone. Even for a quick look at CPU load or disk space, I was logging into each machine over SSH.

I did not want to install another monitoring program on those small servers. Meows uses their existing SSH access and presents Linux system information as cards and charts.

Connection
Android device → SSH → server, directly or through a bastion
Server side
An existing SSH service; no monitoring agent or extra monitoring port

Using Meows

Monitoring

Live metrics and recent history

Each server has a status card for CPU, memory, disk, network and TCP readings. Switch to a chart to see recent history and current process, mount or network interface details.

Choose alert thresholds per server and whether to receive disconnect and recovery notifications. When several thresholds are exceeded, Meows sends a combined notification.

Shell · Lens

Query addresses from terminal output

Tap a recognized IP address, domain, URL or permission string in the terminal or a Docker log. Lens lists the queries and actions available for that value.

Queries and web links are opened when you select an action. Lens does not execute commands automatically.

Other tools

Docker, tunnels and other tools

When your SSH account has access to Docker, you can view container status and logs or start and stop containers. SSH tunnels support local and remote forwarding, including connections through a bastion host.

Network queries, conversion tools, and the Linux and C manuals are in Settings. They can be used without connecting a server.

docker logs -f web openssl s_client -connect example.com:443 dig +short example.com chmod 755 deploy.sh

Credentials and data

DNS, WHOIS and TLS queries make network connections when you use them. Queries against the local IP database stay on the device.

Read the privacy policy →
SSH credentials
SSH passwords and private keys are encrypted on your device and protected using Android Keystore.
Monitoring data
Monitoring history is stored on your device. It is not sent to Meows or other third parties.
Connection path
Your phone connects to the servers you configure over SSH, directly or through a bastion. Meows has no relay service.
Optional backup
Optional backups are encrypted on the device and stored in your own Google Drive account's hidden app data folder. Monitoring history is not included.

Thanks to the people who helped test

Before you start

Do I need to install anything on the server?

No additional monitoring software is needed. Use an existing SSH service with an account that can read the required system information.

Can I connect through a bastion host?

Yes, if the bastion can reach your target server. Monitoring, terminal sessions and tunnels can all use it.

Which Android version is required?

Android 14 or later.

Is there an iOS version?

No iOS version is available at the moment.
